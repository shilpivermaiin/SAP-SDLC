1.2.2.1. Creation of a new custom report to export BOM data in  excel format

A  new report to export multilevel BOM data in excel format (xlsx or xls) is needed.

Requirement description:

The new export report should have following selection screen (Mock-up)




Selection screen field structure:

[TABLE START]
Field | Description | Domain | Data type
Z_ MATNR | Materialnummer (DE)Material Number (EN) | MATNR | CHAR (18)
Z_WERKS | Plant (EN)Werk (DE) | WERKS | CHAR(4)
Z_DATUV | Valid from (EN)Datum gültig ab (DE) | DATUM | DATS (8)
[TABLE END]

Also the selection should provide the option to select where the output file is going to be generated. Two options should be possible:

Application server (based on the logical path definition selected)
The final path should be them concatenated by using the predefined logical path and adding following file name convention:

xxxx_xx_xx.xlsx


Example of possible export



Local file: in this case the user will select the desired export location. Even in this case, the file name should be automatically proposed within the saving window by using the same naming convention as in the first option

Some extra remarks:
BOM should be always multilevel exploded (materials given in the selection screen will represent the highest level 0 from where the explosion will be propagated downwards to the inferior levels -> if any existing) 
All determined BOM components to one Level 0 Material will have a dedicated section in the output list. No mixture between the components of several Level 0 materials should happen.
Once one Level 0 fully exploded/ displayed then continue with the next one. 

As reference for the selection and program logic, the following report can be used: /SIE/EVN_ZPEA_BOM_DOWNLOAD

In correspondence to the determined BOM components as well as the BOM headers, a set of data should be fetched and exported into the XLSX format (details see below)

The output XLSX file will have the following structure:

Technical Description

[TABLE START]
Step | Description
1 | Create a new report /SIE/EVN_ZPEA_BOM_EXP with a selection screen.
2 | The selection screen should provide Material, Plant, and Date as input parameters. It should also provide an option to select whether the generated file should be downloaded to the local system or saved on the Application Server.
3 | Create a new Logical Path that points to the corresponding physical path on the Application Server.
4 | Based on the selection criteria entered by the user, call Function Module CS_BOM_EXPL_MAT_V2 to perform the BOM explosion and retrieve the required BOM details.
5 | Prepare an Excel file based on the data received from the BOM explosion.
6 | Depending on the file output option selected by the user:For Local System, use GUI_DOWNLOAD to download the file locally.For Application Server, use OPEN DATASET statements to save the file to the configured Application Server path.
